# 快速开始指南

## 一键部署

### 🚀 自动安装（推荐新手）

1. **运行部署脚本**
   ```
   双击 deploy_windows.py
   ```

2. **配置系统**
   - 按提示输入API密钥
   - 等待依赖包自动安装完成

3. **启动系统**
   ```
   双击 start_web.bat
   ```

4. **访问界面**
   ```
   浏览器打开：http://localhost:5000
   ```

## 手动部署

### 📋 环境准备

1. **检查Python版本**
   ```cmd
   python --version
   ```
   > 需要 Python 3.8 或更高版本

2. **创建虚拟环境**
   ```cmd
   python -m venv venv
   ```

3. **激活虚拟环境**
   ```cmd
   venv\Scripts\activate
   ```

4. **安装依赖**
   ```cmd
   pip install -r requirements.txt
   ```

### ⚙️ 系统配置

1. **创建配置文件**
   ```cmd
   copy .env.example .env
   ```

2. **编辑配置**
   - 打开 `.env` 文件
   - 设置 `HEPAI_API_KEY=你的密钥`
   - 保存文件

3. **测试配置**
   ```cmd
   python main.py --check
   ```

### 🌟 首次使用

1. **启动Web服务**
   ```cmd
   python main.py --mode web
   ```

2. **访问系统界面**
   - 浏览器访问：http://localhost:5000
   - 看到欢迎页面表示启动成功

3. **创建第一个项目**
   - 点击"开始创作"
   - 选择小说类型和风格
   - 输入核心设定
   - 等待大纲自动生成

## 常用操作

### 📖 创作管理

**创建新大纲**
1. 主页 → "创建大纲"
2. 选择创作模式：
   - 自主模式：系统独立构思
   - 协作模式：结合用户创意
3. 填写基本信息
4. 提交等待生成

**生成新章节**
1. 章节页面 → "生成章节"
2. 系统自动规划内容
3. 实时查看生成进度
4. 完成后可预览和编辑

**查看进度**
- 主页显示总体进度
- 章节页面显示详细统计
- 字数、完成度实时更新

### 🔍 智能检索

**内容问答**
1. 访问问答页面
2. 输入问题（如："主角叫什么名字？"）
3. 系统智能分析已有内容
4. 返回准确答案和相关章节

**快速查找**
- 支持角色名、地名、情节关键词
- 自动关联相关章节内容
- 提供上下文信息

### 📊 系统管理

**设置自动创作**
1. 设置页面 → "创作计划"
2. 设置每日生成时间
3. 配置每天章节数量
4. 启用自动模式

**数据备份**
- 系统自动备份章节内容
- 手动导出：设置页面 → "导出数据"
- 支持多种格式：TXT、DOCX、JSON

**监控系统状态**
- 主页显示系统运行状态
- 资源使用情况实时监控
- 异常情况自动报告

## 启动脚本说明

### 🎯 便捷启动

**Web界面模式**
```cmd
start_web.bat
```
- 启动完整的Web服务
- 适合日常创作使用
- 功能最全面

**命令行模式**
```cmd
start_cli.bat
```
- 文本界面操作
- 适合高级用户
- 资源占用更少

**开发环境**
```cmd
activate_venv.bat
```
- 激活Python虚拟环境
- 用于开发和调试
- 可手动运行各模块

## 故障排除

### ❗ 常见问题

**Q: 无法访问Web界面**
- 检查端口5000是否被占用
- 确认防火墙设置
- 尝试重启系统

**Q: 章节生成失败**
- 验证API密钥是否正确
- 检查网络连接
- 查看错误日志

**Q: 系统运行缓慢**
- 检查内存使用情况
- 关闭不必要的程序
- 调整并发设置

### 📋 诊断步骤

1. **检查系统状态**
   ```cmd
   python main.py --check
   ```

2. **查看日志文件**
   ```
   logs/ 目录下的最新日志
   ```

3. **重启系统**
   ```cmd
   # 停止服务
   Ctrl+C
   
   # 重新启动
   start_web.bat
   ```

### 📞 技术支持

**日志文件位置**
- `logs/web_app_*.log` - Web服务日志
- `logs/novel_system_*.log` - 创作系统日志
- `logs/qa_system_*.log` - 问答系统日志

**配置文件位置**
- `.env` - 环境变量配置
- `config.yaml` - 系统参数配置
- `requirements.txt` - 依赖包列表

## 高级配置

### 🛠️ 性能优化

**调整并发设置**
编辑 `config.yaml`：
```yaml
scheduler:
  max_workers: 3  # 调整并发线程数
  
chapter:
  default_length: 3000  # 调整默认字数
```

**内存优化**
- 减少并发线程数
- 降低默认章节长度
- 定期清理日志文件

**存储管理**
- 定期备份 `data/` 目录
- 清理过期的日志文件
- 监控磁盘空间使用
